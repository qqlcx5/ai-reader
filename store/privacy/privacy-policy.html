AuraMind Privacy Policy

Last updated: 2026-07-03 · Effective immediately

Short version: AuraMind stores everything locally in your browser. We do not collect, transmit, sell, or share any of your data. The only network requests are made by you, directly to AI and storage services that you configure.

1. Overview

AuraMind ("the extension", "we", "our") is a Chrome / Firefox / Edge extension that helps you clip, summarize, highlight, and review web content. This policy explains what data the extension handles, in plain language.

2. Data We Do Not Collect

AuraMind has no servers. We do not run analytics, telemetry, crash reporting, or any kind of data collection. We do not have access to:

  • Your browsing history
  • The pages you clip
  • Your highlights, notes, or chat history
  • Your AI API keys or sync credentials
  • Your IP address, device identifiers, or any usage statistics

3. Data Stored Locally in Your Browser

All user-generated content is stored in your browser via IndexedDB. This includes:

  • Clipped articles (title, URL, content, metadata)
  • Highlights and notes
  • Chat conversations with AI
  • Configured AI model providers (name, base URL, API key)
  • Configured sync destinations (WebDAV / S3 credentials)
  • User settings and preferences
  • RSS feed subscriptions

This data never leaves your device unless you explicitly enable a feature that sends it elsewhere (see §4).

4. Optional User-Initiated Data Flows

The extension contains two optional features that send data outside your browser. Both are disabled by default and only activated when you configure them.

4.1 AI API Calls

When you click "Ask AI" or trigger an auto-analysis, the extension sends the relevant text (usually the page content, your question, and the conversation history) to a model provider you have configured in the settings. The extension never proxies these requests through any server we operate.

Common providers users configure include: OpenAI, Anthropic, Google Gemini, DeepSeek, Ollama (local), LM Studio (local), or any OpenAI-compatible endpoint.

The data is subject to the privacy policy of whichever provider you choose. AuraMind does not log or store the contents of these requests.

4.2 Cross-Device Sync

If you enable the sync feature, the extension uploads your local data (articles, highlights, conversations) to a storage destination you have configured. Supported destinations include:

  • WebDAV servers (e.g. Nextcloud, 坚果云, Apache mod_dav)
  • S3-compatible object storage (e.g. Cloudflare R2, AWS S3, MinIO, Backblaze B2)

The extension authenticates directly with your chosen destination using credentials stored locally in IndexedDB. AuraMind operators have no access to these credentials or to your synced data.

5. Permissions Explained

The extension requests the following browser permissions, each with a narrow purpose:

  • sidePanel — render the workspace and chat UI next to the active tab.
  • activeTab — read the URL and title of the tab you are currently viewing (required to start a clip).
  • scripting — inject the content extractor into the active page so the extension can read the rendered DOM.
  • storage — persist user settings and the local IndexedDB store.
  • tabs — re-open the side panel when you switch tabs and broadcast tab-change events to the workspace.
  • windows — manage the optional popped-out workspace window.
  • alarms — schedule periodic RSS feed refreshes.
  • <all_urls> — required to clip content from any site you visit.

The extension never reads page content from a tab you are not actively clipping.

6. Third-Party Services

The extension itself does not embed any third-party trackers, ad networks, or analytics SDKs. The only third-party services it can talk to are the ones you configure (see §4).

7. Children's Privacy

The extension is not directed at children under 13, and we do not knowingly collect any data from children.

8. Changes to This Policy

If we make material changes, we will update the "Last updated" date above and announce the change in the extension's release notes. Continued use of the extension after a change constitutes acceptance of the updated policy.

9. Open Source

AuraMind is open source. You can audit every line of code, build it yourself, and verify the claims in this policy. The source repository is linked from the Chrome Web Store listing.

10. Contact

For privacy questions or to report an issue, please open an issue on the GitHub repository linked from the Chrome Web Store listing. We do not operate a support email for privacy inquiries.
