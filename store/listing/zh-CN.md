## 详细描述
```markdown
# AuraMind — 你的 AI 第二大脑

不再淹没在标签页里。AuraMind 把网页变成可复习、可回顾的个人知识库。

## ✂️ 一键剪藏
一键将文章、博客、文档保存为干净的 Markdown。自动提取正文、作者、发布日期、封面图。
支持所有站点；PDF 与 arXiv 论文直接取全文，YouTube 视频自动提取字幕，
播客/会议音频可转写为文字。右键菜单与快捷键随时可剪。

## 🤖 AI 摘要与侧边栏对话
让 AI 总结、翻译、回答关于当前页面的问题。侧边栏异步运行 — 浏览不停，AI 在后台干活。

## 🖍️ 高亮与浮动工具栏
在任意网页高亮任意段落。浮动工具栏让你保存高亮、向 AI 提问、加入复习计划。

## 🔁 间隔重复复习（SM-2 算法）
用 AI 从高亮一键生成问答卡或挖空卡，SM-2 算法（Anki 背后的科学）自动安排每日复习：
连续打卡、到期角标提醒、每日新卡上限、旧文重温。闪卡可推送到 Anki（导出或 AnkiConnect 直连）。
读一次，记一辈子。

## 📡 RSS 阅读器（自动发现）
一键订阅 RSS。扩展按计划抓取，按内容哈希去重；支持 OPML 导入导出，
订阅 Newsletter（自托管收件箱），播客条目可一键转写。

## 🕸️ 知识图谱与导出
用 [[双向链接]] 连接文档，图谱视图可视化你的第二大脑；相关文档自动推荐。
一键导出 Obsidian 兼容 Markdown ZIP（含高亮）、Anki 卡片或全库 JSON 备份。

## 🔄 跨设备同步
通过 WebDAV（Nextcloud、坚果云等）或任意 S3 兼容存储（Cloudflare R2、AWS S3、MinIO、Backblaze B2）
进行端到端同步。基于向量时钟的冲突解决，零冲突。闪卡与复习进度一并同步。

## 🔒 本地优先 & 隐私保护
- 所有内容存储在浏览器本地 IndexedDB
- AI 请求发往你配置的模型服务商 — 无中间商
- 无追踪、无分析、无第三方数据共享
- 开源（GitHub）

## 🧠 为谁而生
- 在 PDF 和博客里挣扎的研究者
- 收藏了 N 个「待读」却从不读文档的开发者
- 复习单词和摘录的语言学习者
- 搭建第二大脑的知识工作者
```

## 权限说明（Chrome Web Store 审核用）

| 权限 | 用途 |
|------|------|
| `sidePanel` | 在标签页旁显示工作区/对话 UI。 |
| `activeTab` | 读取用户当前标签页的 URL 和标题（剪藏流程需要）。 |
| `scripting` | 注入内容提取脚本到当前页，以读取 DOM。 |
| `storage` | 持久化设置、模型配置和本地 IndexedDB 数据。 |
| `tabs` | 切换标签时重新打开侧边栏、广播标签事件。 |
| `windows` | 管理可选的弹出工作区窗口。 |
| `alarms` | 定时抓取 RSS 订阅、刷新复习角标。 |
| `offscreen` | 后台解析 RSS 正文（Chromium 特有）。 |
| `contextMenus` | 右键菜单「剪藏此页面 / 保存选中文字」。 |
| `http://127.0.0.1/*`、`http://localhost/*` | 可选的 AnkiConnect 直推（仅本机）。 |
| `<all_urls>` | 剪藏任何用户访问的网站所必需。 |

## 数据使用（隐私标签页）
```
AuraMind 不收集、不传输、不出售、不与任何第三方共享用户数据。
所有用户内容（剪藏文章、高亮、模型、设置）存储在用户浏览器的 IndexedDB 中。

用户主动发起的可选数据流：
- AI API 调用：发送至用户自己配置的模型服务商。AuraMind 不代理、不记录。
- 同步：若用户启用，内容同步至用户自己配置的存储目的地（WebDAV 或 S3 兼容存储）。
  AuraMind 拿不到这些凭证。
```
