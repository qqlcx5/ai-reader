# 故障排除指南

## 页面未提取

**现象**：侧边栏显示「还没有页面上下文」或 Popup 显示「未提取页面」。

**可能的解决方法：**

1. **手动点击刷新**：在侧边栏顶部点击 ↻ 按钮手动触发提取。如果页面内容出现，说明自动提取超时或内容脚本加载延迟。

2. **检查页面是否为受限页面**：AI Reader 无法在 `chrome://`、`chrome.google.com`、`chromewebstore.google.com` 等页面上运行。请在普通网页上使用。

3. **重新加载扩展**：
   - 打开 `chrome://extensions`。
   - 找到 AI Reader，点击刷新图标（↻）。
   - 刷新目标页面，重新按 `Alt+S`。

4. **查看控制台错误**：
   - 在目标页面按 `F12` 打开开发者工具。
   - 切换到 Console（控制台）标签。
   - 如果有 `[AI Reader] Content script loaded on` 消息，说明内容脚本已注入。
   - 查找 `[M2]` 开头的错误消息。

## 模型无响应

**现象**：选择模型后发送消息，模型卡片一直显示「等待中」或「pending」。

**可能的原因和解决方法：**

1. **API Key 无效**：
   - 打开设置 → Provider，检查 API Key 是否正确。
   - 某些 Provider（如 OpenAI）的 API Key 以 `sk-` 开头。

2. **模型名不正确**：
   - 检查模型名是否完全匹配 Provider 支持的模型 ID。
   - 例如：`gpt-4o` 不是 `gpt-4`。

3. **网络问题**：
   - 某些地区可能需要代理才能访问 OpenAI/Anthropic API。
   - 如果使用自定义 Base URL，确保地址正确且可达。

4. **Provider 未启用**：
   - 在设置 → Provider 中检查 Provider 是否已启用（Enabled 开关）。

## 流式输出中断

**现象**：模型开始回复但中途停止，状态变为「error」或「aborted」。

**可能的原因：**

1. **手动中断**：你可能按下了中断按钮。
2. **网络中断**：检查网络连接。SSE 流式连接对网络波动敏感。
3. **API 超时**：某些 Provider 有较短的超时限制（如 Gemini 免费版）。
4. **内容被过滤**：如果提示词触发了 Provider 的内容安全策略，API 可能提前结束流。

## 侧边栏无法打开

**现象**：按 `Alt+S` 或点击扩展图标无反应。

**解决方法：**

1. **检查快捷键冲突**：
   - 打开 `chrome://extensions/shortcuts`。
   - 确认 AI Reader 的快捷键已正确注册。
   - 如果有冲突，可以手动修改快捷键。

2. **检查浏览器支持**：
   - Side Panel API 需要 Chrome 116+。
   - 在不支持的浏览器中，可以使用 Popup 模式。

3. **重新固定扩展**：
   - 点击 Chrome 工具栏的拼图图标。
   - 找到 AI Reader，点击图钉图标固定到工具栏。

## 设置未保存

**现象**：填写了 Provider/Api Key 后刷新页面，设置消失。

**可能的原因：**

1. **存储限制**：`chrome.storage.local` 有 5MB 配额。如果存储了大量对话数据，可能导致设置无法保存。清理历史记录或在设置页手动导出备份。

2. **扩展重装**：卸载扩展会清除所有本地数据。卸载前务必导出设置备份。

## 自动备份失败

**现象**：看到备份错误提示。

**解决方法：**

1. **检查 WebDAV 配置**：确认 URL、用户名、密码正确。
2. **检查网络连接**：WebDAV 服务器必须可达。
3. **检查路径权限**：确保 WebDAV 用户对备份目录有写入权限。

## RSS 抓取失败

**现象**：订阅源显示错误。

**可能的原因：**

1. **URL 无效**：确认 RSS 订阅源 URL 正确且可访问。
2. **格式不受支持**：目前支持 RSS 2.0、Atom 和 JSON Feed。
3. **抓取间隔过短**：如果设定了过短的间隔（< 1 分钟），可能会被服务器限流。

## 已知限制

| 限制 | 说明 |
|------|------|
| 侧边栏宽度 | 不可调整 |
| 历史记录搜索 | 标题搜索为前缀匹配，全文搜索为 Worker 逐条匹配。海量数据时速度可能下降。 |
| S3 备份 | 尚不支持 S3 兼容存储。仅支持 WebDAV。 |
| 浏览器支持 | 需要 Chrome 116+（Side Panel API）。Firefox 支持有限。 |
| API Key 存储 | 明文存储。不支持加密存储。 |
| 自动备份 | 仅全量备份，不支持增量。 |

## 获取帮助

如果你遇到了以上未覆盖的问题：

1. 检查 Chrome 开发者工具控制台是否有错误日志。
2. 在 [GitHub Issues](https://github.com/your-repo/ai-reader/issues) 提交问题。
3. 提交问题时包含：
   - 浏览器版本
   - 扩展版本
   - 复现步骤
   - 控制台错误截图
