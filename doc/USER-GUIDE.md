# AI Reader 用户指南

AI Reader 是一个浏览器扩展，它使用 AI 模型帮助你阅读和理解网页内容，支持多模型并发对话、高阶工作流和 RSS 订阅管理。

## 安装

### 前置要求

- Chrome 116+（推荐）或 Firefox 120+
- 至少一个 LLM API Key（OpenAI / Anthropic / Gemini 等）

### 安装步骤

1. 从 [Releases](https://github.com/your-repo/ai-reader/releases) 下载最新版本。
2. 打开 `chrome://extensions`。
3. 开启**开发者模式**。
4. 点击**加载已解压的扩展程序**，选择 `dist/chrome-mv3` 目录。
5. 将扩展固定到工具栏以便快速访问。

### 开发模式

```bash
pnpm install
pnpm dev
```

这会打开一个 Chrome 实例，扩展已自动加载。

## 快速开始

### 1. 配置 AI Provider

1. 点击扩展图标 → **设置**。
2. 在 **Provider** 选项卡中点击**新增 Provider**。
3. 选择 Provider 类型（OpenAI / Anthropic / Gemini / Custom）。
4. 填入 API Key 和模型名，点击保存。

> API Key 以明文存储在本地浏览器。不要在共享/公共设备上使用。

### 2. 提取页面上下文

- 按 **Alt+S** 打开侧边栏并自动提取当前页面。
- 或点击扩展图标，选择**打开侧边栏**。

侧边栏顶部会显示页面标题、字数和提取状态。

### 3. 开始对话

1. 在侧边栏下方选择要使用的模型（1~4 个）。
2. 输入你的问题，按 Enter 发送。
3. 多个模型的回复会以并排栏目实时流式展示。

### 4. 管理历史记录

侧边栏底部点击**历史**图标，可以查看、搜索和恢复过去的对话。

## 功能详解

### 上下文提取

AI Reader 使用三级降级策略提取网页正文：

1. **Readability**（Mozilla 引擎）— 提取文章主体，输出 Markdown。
2. **Defuddle** — 异步提取，8 秒超时。
3. **innerText** — 兜底方案，移除导航/页脚后提取纯文本。

提取结果包含完整内容，不截断。对于超过 1MB 的超大文本，系统会自动分片传输。

### 上下文锚定

切换标签页时，AI Reader 不会自动刷新上下文。你之前提取的页面保持为对话上下文，直到你手动点击刷新按钮。

### 多模型并发

- 同时选择 1~4 个 Provider，向它们发送相同问题。
- 每个模型独立流式输出，互不阻塞。
- 底部显示每个模型的性能指标：耗时、首 Token 时间（TTFT）、Tokens/s、费用估算。
- 支持对单个模型重试或以此继续追问。

### 高阶工作流

#### 圆桌讨论（Roundtable）

为不同模型设置不同的角色提示词，让它们在同一个问题上从不同角度回答。

**应用场景：**

- 代码审查：红方挑刺、蓝方辩护
- 文章分析：正反观点对比
- 写作改进：语法、风格、结构各自评审

#### 接力链（Relay Chain）

配置串行流水线，上游模型的输出自动作为下游模型的输入。

**应用场景：**

- 翻译 → 润色 → 本地化适配
- 摘要 → 要点提取 → 待办事项生成
- 草稿 → 审核 → 终稿

### RSS 订阅管理

在设置页的 **RSS** 选项卡中配置订阅源：

1. 启用 RSS 抓取。
2. 设置抓取间隔（默认 60 分钟）。
3. 添加订阅源 URL。
4. 可选：启用 AI 摘要，抓取时自动为每篇文章生成三句摘要。

未读条目数量会显示在扩展图标角标上。

### 导出与同步

在设置页的 **Sync** 选项卡中配置：

- **WebDAV 同步**：连接 WebDAV 服务器（如 Nextcloud），自动备份对话记录。
- **Obsidian 集成**：一键将当前对话导出为 Obsidian 笔记。
- **Zip 导出**：在 Web Worker 中打包所有对话和设置为 `.zip` 文件。
- **自动备份**：每日凌晨自动上传全量备份到 WebDAV。

| 操作 | macOS | Windows/Linux |

| 切换侧边栏 | `Alt+P` | `Alt+P` |

> 快捷键可在 `chrome://extensions/shortcuts` 中自定义。

## 界面构成

### 侧边栏（主界面）

1. **顶部状态栏**：当前页面标题、字数、提取状态、刷新按钮。
2. **对话工作区**：消息列表 + 多模型回复卡片。
3. **底部输入区**：消息输入框 + 模型选择器。

### 弹出窗口（PopUp）

1. **上下文摘要**：上次提取的页面标题和字数。
2. **操作按钮**：打开侧边栏、提取内容、进入设置。

### 设置页

1. **Provider**：管理 LLM API 配置。
2. **Prompts**：自定义提示词模板。
3. **Sync**：导出与备份配置。
4. **RSS**：订阅源管理。
5. **Advanced**：主题、实验功能。

## 隐私说明

- API Key 以明文存储在 `chrome.storage.local`。参见 [安全须知](PROVIDER-SETUP.md)。
- 所有 LLM 请求直接发送到你配置的 Provider，不经过中间服务器。
- 提取的内容仅存储在本地 IndexedDB 中，不会自动上传。
- RSS 抓取内容仅存储在本地。
