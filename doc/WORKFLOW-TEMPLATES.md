# 工作流模板指南

AI Reader 支持两种高阶工作流：**圆桌讨论（Roundtable）** 和 **接力链（Relay Chain）**。工作流模板可以保存和复用。

## 内置模板

系统自带了两个内置模板（不可编辑），可用于快速体验：

| 模板名 | 类型 | 节点数 | 用途 |
|--------|------|--------|------|
| 观点交锋 | 圆桌 | 3 | 红方挑刺 / 蓝方辩护 / 中立总结 |
| 递进审校 | 接力链 | 3 | 初步审校 → 深度审查 → 终审润色 |

## 创建模板

1. 在侧边栏的工作流页面，点击 **+ 新圆桌** 或 **+ 新接力链**。
2. 填写模板名称和描述（可选）。
3. 添加和配置节点。
4. 点击 **保存模板**。

### 节点配置

每个节点包含：

| 字段 | 说明 |
|------|------|
| 名称 | 节点显示名，如「红方批评家」 |
| Provider | 绑定到已配置的 LLM Provider |
| 角色提示词 | 该节点的系统角色提示词 |
| 上游节点（接力链） | 该节点的输入来源 |

### 角色提示词示例

**圆桌讨论：**

```
- 红方：你是一个严格的代码审查者。请从安全性、性能、可维护性三个角度挑出所有问题。
- 蓝方：你是一个辩护律师。请从实用主义和交付压力角度为代码的现状辩护。
- 中立：你是一个架构师。请总结红蓝双方观点，给出折中方案。
```

**接力链：**

```
- Step 1（翻译）：请将以下英文翻译为中文，保持技术准确性。
- Step 2（润色）：请优化上述中文翻译，使其更符合中文阅读习惯。
- Step 3（摘要）：请从上述最终版本中提取 3 个关键要点。
```

## 运行工作流

1. 选择一个模板或新建一个临时模板。
2. 在**运行问题**输入框中输入你的问题或内容。
3. 点击 **运行** 按钮。

### 圆桌讨论

所有节点并发执行，每个节点接收到相同的用户问题 + 节点特有的系统提示词。

```
用户问题 → [红方 Provider + 角色提示词] ──→ 红方回复
         → [蓝方 Provider + 角色提示词] ──→ 蓝方回复
         → [中立 Provider + 角色提示词] ──→ 中立回复
```

### 接力链

节点按拓扑顺序串行执行，上游节点的输出自动拼接到下游节点的输入。

```
用户问题 → [Step 1 Provider] → 输出1
输出1 → [Step 2 Provider (依赖 Step 1)] → 输出2
输出2 → [Step 3 Provider (依赖 Step 2)] → 输出3
```

**依赖关系：** 一个节点可以依赖多个上游节点。例如，Step 3 可以同时依赖 Step 1 和 Step 2 的输出：

```
用户问题 → [Step 1] → 输出1
用户问题 → [Step 2] → 输出2
输出1 + 输出2 → [Step 3] → 输出3
```

## 模板编辑

### 添加节点

点击 **+ 节点** 按钮添加新节点。接力链中可以配置上游依赖关系。

### 删除节点

点击节点右上角的删除按钮。删除节点后，下游节点的依赖关系会自动失效（需手动修正）。

### 重排顺序

节点的顺序由其 `order` 字段决定。对于接力链，拓扑排序会自动确定执行顺序。

## 模板校验

保存和运行模板时，系统会进行以下校验：

- **名称非空**：模板名称不能为空。
- **节点列表非空**：至少需要 1 个节点。
- **Provider 已配置**：每个节点必须绑定一个已配置且已启用的 Provider。
- **提示词非空**：每个节点的角色提示词不能为空。
- **无循环依赖**（接力链）：拓扑排序会检测循环依赖。如果检测到循环，保存/运行将被拒绝。

## 结果与保存

工作流完成后，你可以：

1. **保存到历史**：将工作流结果保存为一条对话记录，可在历史列表中查看。
2. **直接关闭**：结果仅保留在当前会话中，关闭后丢失。
3. **自动保存**：工作流成功完成后会自动保存到历史。

## 常见模板示例

### 文章分析圆桌

| 节点 | 角色 | 提示词 |
|------|------|--------|
| 事实核查 | 事实核查员 | 请核查文章中的数据和引用，标记任何可疑或不准确之处。 |
| 立场分析 | 立场分析师 | 请分析作者的观点立场、论证方式和潜在偏见。 |
| 可读性 | 编辑 | 请评估文章的可读性和结构清晰度。 |

### 内容创作接力链

| 节点 | 依赖 | 提示词 |
|------|------|--------|
| 大纲生成 | — | 根据用户问题，生成文章大纲。 |
| 正文撰写 | 大纲生成 | 根据大纲撰写完整的文章正文。 |
| 标题优化 | 正文撰写 | 根据正文内容，提供 5 个备选标题。 |
