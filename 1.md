  ## Core Features to Implement (from PRD)
  1. **Content extraction** from web pages using defuddle (3-tier fallback: defuddle → readability → innerText)
  2. **Multi-model parallel LLM querying** — send same content to multiple providers simultaneously, stream results independently
  3. **Side Panel with columnar layout** — show all model responses side by side with streaming
  4. **Provider abstraction layer** — unified interface for OpenAI, Anthropic, Gemini, Ollama, LM Studio, custom endpoints
  5. **Independent stream management** — each model's stream can be cancelled independently, error isolation
  6. **Follow-up questions** — per-model conversation history
  7. **Export** — Markdown, PDF, Obsidian URI, Notion API
  8. **Highlight system** — text selection → highlight → persist → show in side panel
  9. **Options page** — API key config, model management, template management
  10. **Popup** — quick trigger for summary, model preset switching
  11. **Cost estimation** — estimate tokens before sending, show actual usage after
  12. **Keyboard shortcuts** — Alt+S to summarize, Alt+Shift+S toggle side panel, etc.
